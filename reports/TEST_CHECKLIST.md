# Checklist Penyerahan

## Sebelum backtest

- [ ] EA berhasil dikompilasi tanpa error di MetaEditor.
- [ ] Nama simbol aktual dicatat dari Market Watch.
- [ ] Contract specification setiap simbol disimpan sebagai screenshot.
- [ ] Deposit, mata uang, dan leverage tester dibuat konsisten.
- [ ] Mode Every tick based on real ticks dipilih.
- [ ] Rentang tujuh tahun telah tersedia.

## Untuk setiap instrumen

- [ ] Baseline backtest selesai.
- [ ] Optimasi in-sample selesai.
- [ ] Forward test selesai.
- [ ] Full-period backtest kandidat final selesai.
- [ ] Stress test spread/delay selesai.
- [ ] File `.set` final disimpan.
- [ ] Laporan HTML disimpan.
- [ ] Screenshot settings dan summary disimpan.
- [ ] Baris `BACKTEST_RESULTS.csv` diisi.
- [ ] Bulan rugi dihitung per tahun kalender.

## Sebelum dikumpulkan

- [ ] Tidak ada password, OTP, nomor akun, atau server pribadi dalam proyek.
- [ ] Laporan PDF sama dengan hasil HTML.
- [ ] Semua klaim angka memiliki bukti report.
- [ ] README mencantumkan cara instalasi dan reproduksi.
- [ ] Commit/tag final GitHub dibuat.
